# Cadastro de Amigos

Sistema web desenvolvido para cadastro e gerenciamento de amigos.

## Sobre o projeto

O projeto permite que o usuário faça login no sistema e gerencie informações de amigos cadastrados.

É possível:

- Cadastrar amigos
- Visualizar a lista de amigos
- Editar informações
- Excluir cadastros

## Tecnologias utilizadas

- PHP
- MySQL
- HTML
- CSS
- W3.CSS
- XAMPP

## Banco de dados

O sistema utiliza um banco de dados MySQL para armazenar as informações dos amigos.

A tabela `amigo` possui os seguintes campos:

- `idamigo`
- `nome`
- `apelido`
- `email`

## Funcionalidades

### Login
Sistema de autenticação para controlar o acesso às funcionalidades.

### Cadastro
Permite cadastrar um amigo informando nome, apelido e e-mail.

### Consulta
Permite visualizar os amigos cadastrados e pesquisar informações.

### Edição
Permite alterar os dados de um amigo já cadastrado.

### Exclusão
Permite remover um amigo do banco de dados.

## Objetivo

O objetivo do projeto é demonstrar, na prática, o desenvolvimento de um sistema web utilizando PHP integrado a um banco de dados MySQL.
